## 维护规则

- 方案文档顶部写明基线日期，并明确“已实现 / 计划 / 历史”状态。
- 接口、枚举、中断 payload 变化时，同步更新后端、前端类型和相关协议文档。
- 不在多个文档维护同一份待办；近期优先级以“项目现状评审与改进路线”为准。
- 运行时 DM 失败策略只有显式失败，不增加 mock、模板或启发式回退。测试替身只允许存在于测试边界。
