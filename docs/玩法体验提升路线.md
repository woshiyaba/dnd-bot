# 玩法体验提升路线

> 目标：在不盲目扩充 Agent 数量、完整 5e 规则或长篇内容的前提下，把现有 10～15 分钟垂直切片从“能够跑通”提升为“选择有意义、战斗有变化、结局值得重玩”的短冒险。

## 一、核心判断

项目已经具备一局冒险所需的主要基础能力：

- 玩家可以用自然语言描述行动。
- DM 决策与叙述由真实 LLM 完成。
- 明检定和玩家战斗骰通过中断交给玩家。
- 命中、伤害、HP、先攻和胜负由确定性引擎结算。
- `SessionEngine` 已串联对话、检定、战斗、剧情推进和结局。
- canon 已能约束剧情拍、线索、推进条件和结局。

因此，当前最重要的问题不是继续增加底层能力，而是让玩家感受到：

1. 探索获得的信息会改变后续玩法。
2. 每个战斗回合不只有“普通攻击”一个合理选择。
3. 世界会记住玩家做过的事情。
4. 不同选择会产生明显不同的过程和结局。

第一阶段不追求完整 5e，也不追求大型开放世界。先把《钟楼下的低语》做成一个短小但有决策密度、能产生复盘话题的冒险。

## 二、第一优先级：让线索改变 Boss 战

### 2.1 当前问题

《钟楼下的低语》目前要求玩家收集三条线索：

- 古钟上的熔痕。
- 少女“赫尔薇”的真名。
- 能削弱古钟之灵的圣水。

但线索的主要作用仍是满足进入高潮拍的条件。进入高潮后，玩家基本只能通过击败 Boss 到达胜利结局，容易形成以下体验：

```text
收集三个通行证
  → 登上钟楼
  → 重复普通攻击
  → Boss HP 归零
  → 固定胜利结局
```

探索与战斗之间缺少机械联系，玩家即使认真理解线索，也未必能从结算结果中感受到回报。

### 2.2 目标体验

每一条关键线索都应提供可观察、可结算的优势：

| 线索 | 可解锁行动 | 建议规则效果 | 玩家反馈 |
| --- | --- | --- | --- |
| 古钟熔痕 | 攻击裂缝、利用环境扩大裂口 | 检定成功后降低 Boss AC，或使下一次命中追加伤害 | 明确显示“你发现的弱点生效了” |
| 赫尔薇真名 | 呼唤真名、尝试唤醒少女意识 | 成功后令 Boss 短暂失能，或累计净化进度 | Boss 叙述和行为发生明显变化 |
| 圣水 | 泼洒圣水、涂抹武器、完成净化仪式 | 移除 Boss 护盾、抗性或特殊能力 | 状态栏显示削弱效果及持续时间 |
| 三条线索组合 | 执行完整净化仪式 | 解锁非击杀胜利条件 | 进入“救赎赫尔薇”隐藏结局 |

所有数值效果仍由规则引擎处理。LLM DM 负责理解玩家是否在尝试对应行动、决定需要何种检定，并根据引擎结果叙述反馈；LLM 不直接计算 AC、伤害、状态持续时间或净化进度。

### 2.3 高潮结局分支

第一版至少提供三种结果：

1. **摧毁古钟**：通过战斗将古钟之灵击败，村庄恢复平静，但赫尔薇的灵魂随古钟一同消散。
2. **净化赫尔薇**：玩家正确使用真名、圣水和熔痕线索完成仪式，救下赫尔薇并平息钟声。
3. **钟声不息**：队伍战败，或危险仪式失败并付出无法承受的代价。

可在后续增加带代价的灰色结局，但第一版不需要过多分支。重点是让两种成功路线在玩法、条件和叙述上真正不同。

### 2.4 验收标准

- 三条线索均有对应的确定性规则效果。
- Boss 战中可以看到线索效果触发、持续和结束。
- 玩家可以在“摧毁”和“净化”之间做出选择。
- 净化路线不能只靠 LLM 一句话宣布成功，必须满足引擎维护的条件。
- 结局能够说明玩家使用了哪些线索、采取了什么方式以及产生了什么结果。

## 三、第二优先级：把战斗做成小型战术谜题

### 3.1 当前基础

战斗模型和中断协议已经定义了以下行动：

- 攻击 `attack`
- 技能 `skill`
- 道具 `item`
- 创意行动 `improvise`
- 移动 `move`
- 放弃回合 `pass`

目前前端主要呈现攻击、移动和放弃。技能、道具和创意行动尚未形成完整、易懂的玩家入口，因此后端已有的选择没有充分转化为实际体验。

### 3.2 实施内容

#### 接通已有行动入口

- 在行动面板展示当前可用技能、剩余充能和冷却。
- 展示可用道具、数量、合法目标和预期用途。
- 增加“描述创意行动”入口，让玩家用自然语言说明想法。
- 无合法目标或资源不足的行动应直接禁用，并解释原因。

#### 增加 Boss 攻击预告

Boss 的强力行动提前一回合通过规则状态和叙述预告，例如：

```text
古钟表面的裂纹泛起蓝光，回声正在向前排聚集。
下一回合：对前排所有目标发动“震荡钟鸣”。
```

玩家可以据此选择移动、打断、使用道具、保护目标或抢攻，而不是只比较伤害期望。

#### 让区域移动产生意义

- 不同区域影响近战和远程攻击是否合法。
- Boss 范围攻击只覆盖特定区域。
- 环境机关位于指定区域，必须移动后才能交互。
- 移动的收益和风险应在行动面板中可见。

#### 增加少量环境互动

《钟楼下的低语》第一版只需要 2～3 个环境对象，例如：

- 钟绳：成功破坏后打断 Boss 蓄力。
- 断裂横梁：推倒后造成一次伤害或封锁区域。
- 古钟裂缝：结合熔痕线索产生弱点效果。

环境对象应是封闭、可验证的规则定义。DM 可以把自然语言意图映射到这些对象，但不能临时编造任意数值效果。

### 3.3 创意行动边界

创意行动建议遵循以下流程：

```text
玩家描述想法
  → DM 判断对应的封闭效果和所需检定
  → 玩家提交骰子
  → 引擎计算成败和数值变化
  → DM 根据真实结算叙述结果
```

若玩家的想法无法映射到当前支持的效果，应由真实 LLM DM 明确说明限制或给出可行替代，不使用离线模板或启发式假 DM 推进。

### 3.4 验收标准

- 技能、道具和创意行动均可从前端完成选择与提交。
- 玩家每个关键回合至少能看到两个有意义的合法选择。
- Boss 至少有一个可预告、可规避或可打断的强力行动。
- 至少两个环境对象能被玩家实际利用。
- 战斗流程不需要玩家打开控制台或猜测提交 JSON。

## 四、第三优先级：让世界记住玩家

### 4.1 推荐状态

先增加少量能被玩家理解的长期状态：

- NPC 的信任、恐惧或敌意。
- 是否救助、欺骗、威胁或放弃某个 NPC。
- 是否使用危险力量或破坏重要地点。
- 消耗的关键道具和战斗后留下的伤势。
- 获得的特殊战利品。
- 选择摧毁还是净化古钟。

这些状态应尽量使用 canon 声明的 flag、物品或确定性事件保存。DM 只在白名单范围内声明世界变化，引擎负责验证和写入。

### 4.2 结果反馈

结局页面应展示简短的因果回顾，例如：

```text
你找到了赫尔薇的真名，因此能够在最后一刻唤醒她。
你保留了圣水，并将它用于净化仪式。
你没有摧毁古钟，赫尔薇的灵魂最终得到解脱。
神父艾达记住了你的选择。
```

重点不是生成大量统计，而是让玩家能准确回答：“我的哪一个选择改变了什么？”

### 4.3 验收标准

- 至少三个冒险中的选择会写入可恢复状态。
- 后续叙述会引用这些已发生事件，且不能与状态冲突。
- 结局回顾由确定性事件提供事实，LLM 只负责组织叙述。
- 不同路线的结局卡在标题、事实和情绪上有明显差异。

## 五、第四优先级：加强反馈与沉浸感

### 5.1 骰子和结算反馈

- 提供简短的骰子动画，但最终点数和来源由服务端确认。
- 明确展示检定计算过程，例如：`17 + 4 = 21，成功通过 DC 15`。
- 攻击明确展示命中、未命中、暴击和自然 1。
- 伤害、治疗、状态变化使用不同的视觉反馈。
- 玩家骰、怪物骰和 DM 暗骰都保留来源记录，但不向玩家泄漏不应公开的暗骰内容。

### 5.2 战斗信息

- Boss 蓄力和阶段变化应有明显提示。
- 状态栏展示效果名称、剩余回合和机械影响。
- HP 变化要有动画或短暂高亮。
- 最近结算结果使用简短卡片，不依赖长篇叙述传递规则事实。

### 5.3 探索信息

- 增加线索板，展示玩家确实发现的事实。
- 未发现线索只显示空位或数量，不泄漏具体内容。
- 当前地点、可见出口和明显威胁保持可见。
- DM 流式叙述完成后，行动输入区应给出清晰的可操作状态。

### 5.4 视听范围

第一版无需复杂地图或大量动态素材。优先使用：

- 每个主要场景一张背景图。
- 主要 NPC 和 Boss 的立绘。
- 掷骰、受击、治疗和钟声的短音效。
- 结局卡片和本局回顾。

这些反馈比大地图编辑器更直接地提升当前垂直切片的完成感。

## 六、两周玩法迭代建议

### 第一周：选择真正影响规则

1. 为熔痕、真名和圣水定义封闭的规则效果。
2. 在战斗状态中记录弱点、净化进度和 Boss 蓄力状态。
3. 接通前端技能、道具和创意行动入口。
4. 增加一个可预告的 Boss 强力行动。
5. 增加两个环境互动对象。
6. 增加“摧毁古钟”和“净化赫尔薇”两个成功结局。

第一周验收目标：同一批角色能够通过两种明显不同的玩法完成冒险。

### 第二周：反馈、试玩与调整

1. 增加线索板、结算卡、Boss 预告和状态提示。
2. 增加结局因果回顾。
3. 找 5～10 名不了解代码和剧本的玩家完成试玩。
4. 记录卡关位置、空转回合、行动选择和完成时间。
5. 根据试玩调整线索提示、DC、Boss HP、伤害和技能效果。
6. 修复影响体验的刷新恢复、重复提交、断线和错误提示问题。

第二周验收目标：玩家无需开发者解释即可从开场玩到结局，并能说清自己的选择如何影响结果。

## 七、试玩指标

### 核心指标

- 完成一局的玩家比例。
- 从开场到结局的中位时长。
- 每拍平均空转回合数。
- 战斗中使用过普通攻击以外行动的玩家比例。
- 三条线索各自的使用率。
- 净化路线和摧毁路线的选择比例。
- 玩家结束后愿意尝试另一条路线的比例。

### 观察问题

试玩后询问玩家：

1. 你是否一直知道下一步可以做什么？
2. 哪个选择让你最犹豫？
3. 你发现的线索有没有真正帮到你？
4. 战斗中是否存在“每回合只想普通攻击”的阶段？
5. 你能否说出自己的选择改变了什么？
6. 你是否愿意再玩一次尝试另一种结局？

### 建议体验门槛

- 大多数玩家无需开发者提示即可完成一局。
- 大多数玩家在 Boss 战中至少使用一次非普通攻击行动。
- 玩家能够识别至少一条“探索信息 → 战斗收益”的因果链。
- 空转回合集中在可定位、可修复的少数节点。
- 至少一部分玩家主动表达尝试另一结局的意愿。

## 八、发布前的体验基础

以下事项本身不是玩法内容，但失败时会直接破坏乐趣，应与玩法迭代同步收口：

- 刷新或短暂断线后能恢复到当前中断。
- 双击和网络重试不会重复结算同一行动。
- LLM 超时、输出非法或叙述失败时显式报错，不生成假 DM 内容继续推进。
- 玩家骰缺少合法结果时不静默改由引擎代掷。
- 同一房间的命令按顺序执行，不出现重复回合。
- 前端明确区分“等待 DM”“等待玩家掷骰”“等待玩家选择行动”和“冒险结束”。

可靠性应优先服务于试玩闭环，不在第一阶段扩展与单人垂直切片无关的大型基础设施。

## 九、暂不优先实施

在当前垂直切片证明好玩之前，暂不优先投入：

- 完整 D&D 5e 规则覆盖。
- 大规模法术、职业和怪物库。
- 长篇开放世界。
- 地图或剧本可视化编辑器。
- 复杂角色创建系统。
- 大型背包和经济系统。
- 多 Agent 编排扩张。
- 与单人试玩无关的复杂多人玩法。

这些能力以后可以建设，但不应先于“线索影响规则、战斗存在选择、结局回应玩家”这三个核心体验。

## 十、推荐的第一个开发任务

第一个开发任务建议定义为：

> 将“古钟熔痕、赫尔薇真名、圣水”分别实现为可结算的高潮机制，并为三者组合增加“净化赫尔薇”结局。

该任务能同时验证现有 canon、世界 flag、DM 意图理解、玩家检定、战斗状态、规则结算和最终叙述链路，对当前架构改动可控，又最能直接提升探索价值、战斗深度和重玩意愿。
