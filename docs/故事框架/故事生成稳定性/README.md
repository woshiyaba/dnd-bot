## 共同边界

- 代码只修复能够从确认稿、StoryPlan 或固定协议唯一推导出的值。
- AI 只修复需要理解剧情、语义、动机、线索内容或规则表达的值。
- 所有 AI 修复仍使用真实模型；不增加模板故事、启发式故事或离线 DM 兜底。
- 每次修复都重新经过相同的确定性校验，未经验证的中间结果不得持久化为有效产物。
- 任何局部修复都必须有明确的可修改路径白名单；模型返回白名单外字段时由代码丢弃并记录。
- 一旦问题跨越多个引用对象，修复单元必须扩展到依赖闭包，不能为了“局部”而留下悬空引用。

## 目标结果

完成本组方案后，故事生成应形成固定生产线：

```text
确认稿
  -> StoryPlan 初稿
  -> 代码归一化
  -> 确定性校验
  -> 局部 AI 修复或结构重规划
  -> 代码编译 Canon 不可变骨架
  -> AI 填充创作载荷
  -> 条目级校验与局部修复
  -> 分片持久化
  -> 完整 Canon 校验
  -> 连贯性复核
  -> 草稿
```
