# 统一规则行动协议（v2）

技能、物品与任务特性不再拥有独立的结算分支。三者统一经过：

`ActionDefinition → LLM ActionPlan → commit_action_cost → Engine Executor`

原则仍是：规则归引擎、叙述归 DM、骰子归玩家。LLM 只实例化定义中的模板，不能决定
最终骰值、命中、伤害、HP、物品数量或世界状态。

## ActionDefinition

```json
{
  "id": "apply_frost_talisman",
  "name": "激活寒冰符箓",
  "source_kind": "item",
  "source_ref": "item_frost_talisman",
  "scopes": ["combat"],
  "requirements": {
    "flags": ["clue_sigil_frost"],
    "encounter_ids": ["boss_vermillion_serpent"]
  },
  "targeting": {
    "faction": "enemy",
    "life_state": "alive",
    "range": "melee",
    "min_targets": 1,
    "max_targets": 1
  },
  "usage": {
    "kind": "consume_item",
    "item_id": "item_frost_talisman",
    "quantity": 1
  },
  "contract": {
    "check_templates": [],
    "effect_templates": [
      {
        "id": "weaken_scales",
        "kind": "modify_ac",
        "target_mode": "selected_one",
        "amount": -3,
        "rounds": 100,
        "when": {"outcomes": ["always"]}
      }
    ]
  }
}
```

`usage.kind` 支持 `unlimited`、`skill_resource`、`consume_item`、
`once_per_combat` 和 `once_per_session`。成本统一在计划验证通过后、第一次骰子中断前提交。
每个计划由引擎分配唯一 `plan_id`，已提交 ID 会进入状态，重放不会重复扣除。

## ActionPlan

LLM 只返回模板引用和目标绑定：

```json
{
  "schema_version": 2,
  "definition_id": "invoke_elder_shock",
  "actor_id": "pc_1",
  "selected_target_ids": ["vermillion_serpent"],
  "summary": "借风老灵力震慑火蟒",
  "checks": [
    {
      "id": "call",
      "template_id": "elder_call",
      "target_id": "vermillion_serpent"
    }
  ],
  "effects": [
    {
      "id": "stun",
      "template_id": "stun_serpent",
      "target_id": "vermillion_serpent"
    }
  ]
}
```

校验器会丢弃 LLM 自行填写的机械参数，重新从模板复制骰式、DC 来源、数值、状态、
持续时间和分支；模板缺失、重复、越权目标、未知效果或范围不匹配都会令整份计划失败。
编译器最多纠错两次，仍失败则显式报错，且不消耗行动或资源。

## 检定与效果

检定模板支持 `attack_roll`、`saving_throw`、`ability_check`。玩家控制的掷骰者通过
LangGraph `interrupt()` 中断；怪物和环境使用可播种的引擎 RNG。伤害、治疗和其他数值骰
使用 `effect_roll` 中断，并携带 `action_id`、`effect_id` 与用途。

战斗效果白名单：

- `damage`、`healing`、`temporary_hp`、`revive`
- `add_condition`、`remove_condition`
- `modify_ac`、`modify_attack_bonus`、`move_zone`

世界效果白名单：

- 上述角色 HP / 状态效果
- `set_flag`、`grant_item`、`remove_item`、`discover_clue`
- `move_location`、`transition_beat`

世界效果仍要经过 Canon 的 flag、地点、线索和合法出口校验。不存在自由文本脚本或
`dm_ruling` 降级路径；不能完整表达的规则会显示为禁用，并给出原因。
